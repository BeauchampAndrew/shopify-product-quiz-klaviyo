# Product Finder Quiz for Shopify (saves answers to Klaviyo)

A product finder quiz as a native Shopify theme section: three questions, one per screen, a results page with the top 3 picks and an Add all to cart, and an email step that subscribes the shopper to a Klaviyo list and saves every answer on their Klaviyo profile. No app.

Built with Claude Code on camera for the BS&Co YouTube channel. Install steps, settings and customization prompts go here once the build is done.
